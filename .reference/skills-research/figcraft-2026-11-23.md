# FigCraft 0.10.0 to 0.18.1, for `toghen:figcraft` (23 November 2026)

Read, not measured: the release notes of v0.11.2 to v0.18.1 (`gh release view -R storytold/figcraft`), `docs/control-protocol.md`, `docs/mcp.md` and `docs/cli.md` at tag `v0.18.1`, and `figcraft-cli commands --json` of the installed 0.18.1, kept as [figcraft-commands-0.18.1.txt](figcraft-commands-0.18.1.txt). No app was started and no file was opened. The headless runs of `@toghen/figma` 0.1.16 against `figcraft-cli` 0.18.1 were made by the review of 23 November 2026 (house, `.reference/plans/workspace/review-2026-11-23.md`).

## What changed that Toghen meets

- **A parameter a command does not list is refused** (0.13.1, "commands, MCP tools and batch steps refuse names they don't take"; `control-protocol.md`, *`engine.execute`*: "never ignored"). figma 0.1.15 and earlier sent `node.get` a `depth`; `figma/decisions.md`, 7 November 2026, found every headless run stopping on it against 0.15.1. figma 0.1.16 sends none.
- **`node.get` as a command takes no `depth`** and returns one level of children; the control method `node.get` and MCP's `get_node` take one (`control-protocol.md`, *`node.get`*).
- **`doc.list` gives an agent no paths** (0.13.1, "doc.list gives AI agents and plugins file names, not paths"). MCP sets `agent`, so a headless session gets `{index, id, name, dirty, active}`; a control call that names no `agent` still gets `path` (`control-protocol.md`, *Documents*). figma 0.1.16 finds a `--library` file's tab by its path, so a headless `--library` run fails; the review ran it.
- **`file.save` takes `overwrite`**: without it, a save over what another program wrote since the file was opened or saved is refused.
- **`command.batch` takes `onError` and a step's `as`**; `{"$ref": name}` beside `{"$step": n}`.
- **A request can name its `document`** by id or open path, and a control request can set `timeoutMs`, up to 10 minutes (0.13.1).

## Unchanged for Toghen

Of the 32 commands `figma/cli/*.ts` sends by name, none is gone. Besides the four above, the parameter docs of `node.set`, `style.bind`, `variable.create`, `variable.delete` and `variable.set` grew (percent opacity, descriptions, colour calculations); what Toghen sends is still taken. `library.setVariableMode {library, collection, mode, ids?}` is as in 0.9.0. The control socket's request and reply shapes, `figcraft-cli mcp` with `run_command`, `open_file` and `save_file`, and `--attach` are as the skill says.
