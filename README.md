# toghen-skills

A [Claude Code](https://code.claude.com/docs/en/plugins) plugin marketplace for [Toghen](https://codeberg.org/Toghen), a design-tokens toolkit. It holds one plugin, `toghen`, with three skills: the pipeline from a repository's tokens and component files to CSS, Figma and FigCraft, and what Figma and FigCraft do at the versions pinned. No code.

```bash
claude plugin marketplace add egildo/toghen-skills
claude plugin install toghen@toghen
```

`egildo/toghen-skills` is this repository's mirror on GitHub. The [guide](guide.md) says what each skill teaches and how to update, the [specs](specs.md) how a skill stays pinned to what it describes, and [decisions](decisions.md) what was checked and when.
